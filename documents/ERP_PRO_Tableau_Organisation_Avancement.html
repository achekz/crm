🏗️ Architecture Technique

Frontend — React + TypeScript

  • React 18 + TypeScript (Hooks, typage strict)
  • Ant Design 5 + Tailwind CSS (Composants modernes)
  • React Router DOM v7 (Routes privées, lazy load)
  • Redux Toolkit (Slices, persist, async thunk)
  • Recharts (Dashboards dynamiques)
  • Socket.IO Client (Chat & notifications)

Backend — Node.js + Express

  • Express.js + TypeScript (Sécurité & performances)
  • JWT + bcrypt (Sécurité renforcée)
  • Socket.IO (Chat bidirectionnel)
  • Stripe API (Webhooks, paiements en ligne)
  • Helmet, CORS, Rate Limiting (Sécurité)
  • MongoDB + Mongoose (Modèles + relations)
